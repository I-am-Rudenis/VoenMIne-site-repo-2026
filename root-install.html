Установка корневого сертификата

Зачем это нужно, как проверить подлинность и как установить — по шагам.

Зачем это нужно

Из-за ограничений с выдачей и продлением публичных TLS-сертификатов для сайтов проекта используется собственный корневой сертификат удостоверяющего центра VoenMine Dev Infrastructure. Он нужен, чтобы браузер доверял сертификатам, которыми подписаны наши сайты, и не показывал предупреждение о небезопасном соединении.

⚠️ Установка корневого сертификата — это высокий уровень доверия: такой сертификат технически позволяет его владельцу подписывать HTTPS-соединения для любых сайтов, не только наших. Устанавливайте его только если доверяете источнику, и обязательно сверьте отпечаток ниже перед установкой.

Проверьте подлинность перед установкой

Сравните SHA-256 отпечаток скачанного файла с эталонным значением, опубликованным на независимых каналах:

SHA-256: 00:00:00:...:00:00

Проверить отпечаток можно командой:

openssl x509 -in cert.pem -noout -fingerprint -sha256

Эталонное значение опубликовано также здесь (сверяйте минимум по двум независимым источникам):

  • Официальный сайт проекта → раздел «Безопасность»
  • Репозиторий проекта на GitHub (файл fingerprint.txt)

1 Скачайте сертификат

Архив содержит сертификат в форматах .crt и .pem для разных ОС.

Скачать архив с сертификатом

2 Установите вручную

Windows: дважды кликните по файлу .crt → «Установить сертификат» → «Локальный компьютер» → «Доверенные корневые центры сертификации».

macOS: откройте файл → в «Связке ключей» → категория «Сертификаты» → откройте сертификат → «Доверие» → «Всегда доверять».

Android: Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → «Сертификат ЦС».

iOS: Настройки → профиль загружен → Общие → VPN и управление устройством → установить профиль, затем Настройки → Основные → Об этом устройстве → Доверие сертификатам → включить.

Браузер может потребовать перезапуск после установки.

3 Как убрать сертификат позже

Сертификат можно удалить в любой момент через те же разделы настроек, где он был установлен (хранилище доверенных корневых сертификатов). Это не повлияет на работу остальных сайтов — только наши сайты вновь будут показывать предупреждение о сертификате.
